# Quality Diagnostic App

This is a static GitHub Pages-ready application for the Quality In Practice Quality Diagnostic.

The diagnostic is based on Philip Crosby's Quality Management Maturity Model and uses the five maturity stages:

1. Uncertainty
2. Awakening
3. Enlightenment
4. Wisdom
5. Certainty

## Files

- `index.html` - app shell
- `styles.css` - responsive visual styling
- `quality-data.js` - Crosby-based stages, categories, choices, and recommendations
- `app.js` - scoring, charting, recommendations, print, reset, sample results, and email CTA
